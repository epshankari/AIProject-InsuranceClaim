# AIProject-InsuranceClaim
GenAI project on Insurance Claims Adjudication Assistant

Build a complete, runnable hackathon MVP named Customer Onboarding & KYC Compliance Assistant, based on the attached problem statement. Use Python and Streamlit for the UI. Implement a multi-agent architecture with an orchestrator and at least four specialized agents: (1) Document OCR and field extraction, (2) Identity matching with fuzzy name matching and DOB/address comparison, (3) KYC document validation and sample watchlist screening, (4) Decision and audit-trail generation. Use LangGraph or a simple reliable Python orchestration layer if LangGraph setup is too time-consuming. Add a local vector database such as FAISS or Chroma with sample KYC policy documents and RAG retrieval; show retrieved policy snippets and citations in the results. Support PDF and image uploads, OCR where available, and a clearly labelled synthetic demo mode with preloaded fictional applicants. Detect missing fields, inconsistent values, expired documents where expiry applies, and possible tampering as a review flag rather than claiming definitive forensic detection. Use a fictional local watchlist and attribute-based matching with name, DOB and address to demonstrate false-positive reduction. Do not claim access to real RBI, sanctions, or government databases unless actually configured. Produce only explainable recommendations: APPROVE RECOMMENDATION, REQUEST MORE DOCUMENTS, or ESCALATE TO COMPLIANCE. Never auto-approve a real applicant. Include confidence indicators, reasons, risk flags, a reviewer override, and an audit log. Use MLflow for experiment/run logging if available; otherwise provide a working local audit logger and document the MLflow integration. Provide a polished Streamlit dashboard, sample cases, unit tests, requirements.txt, README.md, .env.example, and a one-command local startup guide. Use synthetic personal data only; never print secrets or log uploaded document contents unnecessarily. First inspect the project folder, then implement the complete application, install dependencies where permitted, run it, execute tests, fix errors, and explain how to launch it.
